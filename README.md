# Космо-класс · сайт 9 «К»

Статический сайт класса школы будущего в космической визуальной концепции. Проект работает без фреймворков: только HTML, CSS и JavaScript.

## Быстрый старт

Проект можно открыть напрямую через `index.html`. Для корректной работы локальных изображений и навигации рекомендуется использовать локальный HTTP-сервер.

### Python

```powershell
python -m http.server 8000
```

После запуска откройте в браузере:

```text
http://localhost:8000/
```

### VS Code

Можно использовать любое расширение для запуска статических сайтов, например Live Server.

## Главная настройка класса

Название класса хранится в одном месте — в файле [site-config.js](site-config.js).

```js
window.SITE_CONFIG = {
  className: '9 «К»',
  classShort: '9К'
};
```

Для смены класса в будущем измените только эти два значения. Скрипт автоматически обновит:

- названия класса в шапках, hero и футерах;
- заголовки и `title` страниц;
- meta description;
- подпись на космической планете;
- текст на страницах профилей учеников.

Не нужно вручную искать номер класса по всем HTML-файлам.

## Главная страница

Главная состоит из нескольких блоков:

1. Hero космо-класса — полноэкранная сцена с планетой 9К, орбитами, ракетой, звёздами и CTA.
2. Список учеников — 30 карточек (29 учеников и один шаблон профиля) с hover-эффектом и переходом в профиль.
3. Команда учителей — карточки всех наставников с фотографиями.
4. Архив наблюдений — подборка фотографий проектов, поездок и событий.

### Анимации hero

В hero используются:

- пульсация и мигание звёзд;
- движение орбит;
- плавное свечение и «дыхание» планеты;
- полёт ракеты с CSS-пламенем;
- pointer-parallax космической сцены на desktop;
- анимированная стрелка прокрутки;
- отключение motion-анимаций при `prefers-reduced-motion: reduce`.

## Ученики

Данные учеников находятся в массиве `students` в [script.js](script.js).

Формат записи:

```js
[
  'Имя Фамилия',
  'Короткая роль или описание',
  'Папка с учеником/FILE.jpg',
  'unique-slug'
]
```

Чтобы добавить ученика:

1. Добавьте папку и фотографию в `Фото 8K/1/Ученики/`.
2. Добавьте новую запись в массив `students`.
3. Укажите уникальный `slug` латиницей.

Профиль откроется по адресу:

```text
pages/students/student.html?id=unique-slug
```

Профиль уже содержит блоки для будущих данных:

- достижения;
- проекты;
- интересы;
- галерея.

## Учителя

Данные учителей находятся в массиве `teachers` в [script.js](script.js).

Формат записи:

```js
[
  'ФИО учителя',
  'Предмет или роль',
  'Путь к фотографии внутри Фото 8K/Учителя/'
]
```

Карточки учителей автоматически рендерятся в секции `data-teachers` на главной странице.

## Страницы проекта

### Новости

## Дизайн-система

Основные CSS-переменные находятся в начале [style.css](style.css):

```css
--ink       основной тёмно-синий цвет;
--blue      голубой акцент;
--blue-deep тёмный голубой для ссылок;
--lime      лаймовый акцент из логотипа;
--paper     светлый фон страниц;
--line      цвет границ;
```

Шрифт заголовков — `Space Grotesk`, основной текст — `Manrope`.

## Адаптивность

В проекте предусмотрены основные режимы:

- desktop — полноразмерный hero и многоколоночные сетки;
- tablet — уменьшенные орбиты и перестроение сеток;
- mobile — отдельная композиция hero, горизонтальная навигация, две колонки карточек учеников и учителей.

Hero рассчитывает высоту относительно шапки:

```css
height: calc(100dvh - var(--header-height));
```

Это предотвращает обрезание нижней стрелки и контента из-за того, что шапка занимает часть viewport.

## Технические ограничения

- чистый HTML/CSS/JavaScript;
- без React, Vue, Bootstrap и других фреймворков;
- локальные изображения используются из папок проекта;
- внешняя загрузка используется только для Google Fonts через `@import`;
- для иконок применяются CSS-формы и текстовые стрелки;
- все интерактивные элементы доступны с клавиатуры;
- motion-анимации отключаются для пользователей, выбравших reduced motion.

Перед передачей проекта проверьте:

1. Открывается ли `index.html` или локальный сервер.
2. Загружается ли логотип.
3. Отображаются ли все карточки учеников и учителей.
4. Открывается ли профиль ученика.
5. Работают ли ссылки на игры, достижения, историю и фотоальбом.
6. Не появились ли битые изображения после добавления новых материалов.
7. Как сайт выглядит на ширине 390px и на desktop.
